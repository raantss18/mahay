Install Pejy first, then start a document.

1. [Install Pejy](install.md) on Windows 11, macOS or Linux.
2. Open Pejy. The start screen has three buttons: **New file**, **Open** and **Open sample magazine**.
3. Click **Open sample magazine** to see a finished layout, or follow [Create a new document](../guides/create-a-document.md) to begin your own.

Pejy also runs in a web browser. See [Which systems does Pejy run on?](../faq/supported-systems.md).
