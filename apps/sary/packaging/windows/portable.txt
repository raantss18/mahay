Sary portable mode

While this file sits next to sary.exe, Sary keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the SaryData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Sary with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Sary for settings
and %LOCALAPPDATA%\Sary\Recovery for crash-recovery autosaves. If SaryData can't be
written (for example on a read-only drive), Sary says so and uses those folders instead.
