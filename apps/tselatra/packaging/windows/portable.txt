Tselatra portable mode

While this file sits next to tselatra.exe, Tselatra keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the TselatraData folder beside it instead of
%APPDATA%\Tselatra. Copy the whole folder to move Tselatra with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Tselatra unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Tselatra) instead.
If TselatraData can't be written (for example on a read-only drive), Tselatra logs a
warning and uses %APPDATA%\Tselatra instead.
