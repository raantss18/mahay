Tsipika portable mode

While this file sits next to tsipika.exe, Tsipika keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the TsipikaData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Tsipika with its
settings. The first time TsipikaData is created, any settings already in
%APPDATA%\Tsipika are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Tsipika loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\Tsipika) instead.
If TsipikaData can't be written (for example on a read-only drive), Tsipika logs a
warning and uses %APPDATA%\Tsipika instead.
