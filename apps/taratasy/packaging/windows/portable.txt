Taratasy portable mode

While this file sits next to taratasy.exe, Taratasy keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the TaratasyData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Taratasy with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Taratasy and
%LOCALAPPDATA%\Taratasy) instead. If TaratasyData can't be written (for example on a read-only
drive), Taratasy says so and uses the per-user folders instead.
