Mahay Trano portable mode

While this file sits next to trano.exe, Mahay Trano keeps its settings, its
download cache and its record of installed apps in the MahayLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Mahay Trano with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Mahay Trano) instead.
If MahayLauncherData can't be written (for example on a read-only drive), Mahay Trano says
so and uses %APPDATA%\Mahay Trano instead.
